# AGENTS.md — Сканер корреспонденции

## Что это
Веб-приложение: фотографируешь письмо (корреспонденцию) — получаешь машиночитаемый текст (OCR).
Пользователь — новичок в программировании, проверяет результат запуском, а не чтением кода.

## Платформа и технологии
- Статический сайт: HTML + CSS + JavaScript, без сборки и без фреймворков.
- OCR: Tesseract.js (подключается с CDN, распознавание идёт в браузере пользователя).
- Хостинг: GitHub Pages — сайт открывается с любого телефона по ссылке.
- Языки распознавания: русский + английский (`rus+eng`).

## Как запустить
- На компьютере: двойной клик по `index.html` (или Live Server в VS Code).
- На телефоне для проверки до выкладки: `python -m http.server 8000` в папке проекта,
  затем открыть на телефоне `http://<IP-компьютера>:8000` (телефон в той же Wi-Fi сети).
- Постоянная ссылка: GitHub Pages (инструкция в README.md).

## Где смотреть ошибки
- На компьютере: консоль браузера (F12 → Console).
- На телефоне: Eruda не подключён; ошибки воспроизводить на компьютере.

## Структура
- `index.html` — разметка страницы.
- `style.css` — стили (мобильный-first).
- `app.js` — вся логика.
- `README.md` — инструкция по выкладке на GitHub Pages.

## Договорённости
- Маленькие шаги: один шаг — одно проверяемое изменение.
- Комментарии в коде — короткие, на русском.
- Настройки (языки OCR, размеры) — в начале `app.js`, чтобы менять без правки логики.
- Никаких новых библиотек без обсуждения.
- При каждом изменении поднимаем `APP_VERSION` в `app.js` на +0.001
  (v0.001 → v0.002 …). Пользователь проверяет по версии, что сайт на GitHub Pages обновился.
